# Nuvotap website

A responsive, static marketing website for Nuvotap, a contactless review-tag business. Built with plain HTML, CSS and JavaScript so it can be hosted easily with GitHub Pages.

## Preview locally
Open `index.html` in a browser. For a more realistic local server, run:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `nuvotap-website`).
2. Upload the contents of this folder to the repository root — `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will provide your live website URL after deployment.

## Before launch
- Replace the enquiry button's demo message in `script.js` with your email, contact form, or checkout URL.
- Add your real prices, delivery details, returns policy, privacy policy and contact information.
- Confirm your final product specifications and compatibility claims.
- Product visuals and logo in `assets/` are illustrative brand assets; replace them with final production photography if needed.

No build tools or dependencies are required.
