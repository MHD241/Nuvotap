GOOD TO KNOW

Questions? Answered.

How does a Nuvotap tag work? +

The tag is set up to open a destination link on compatible smartphones using a contactless tap. The destination can be your review page or another relevant link.

Do customers need to download an app? +

For a standard NFC tap, customers generally don't need a separate app. Device compatibility and settings can vary, so a QR code or short link can be a useful alternative.

Where should I place it? +

Place it on a clean, dry, flat surface where customers can easily see and reach it, such as a checkout counter or reception desk.

Can I link to a page other than Google reviews? +

Yes. The tag can be configured for a suitable destination link. Make sure the link is tested before placing the tag in your business.
